# EduTrack

**Project Overview**

EduTrack is a web application for lecturers to manage and invite students to an educational platform. It provides an efficient, reliable, and data-driven tool to track student presence, generate reports, and manage course rosters.

## Live URL

The project is live at: [www.edutrack.store](https://www.edutrack.store)

---

## Key Features

* **Instructor Dashboard:** A central hub for managing all courses, viewing attendance statistics, and accessing student information.
* **Course Management:** Easily create, edit, and delete courses for the semester.
* **Student Invitation System:** Securely invite and enroll students into courses via email.
* **Smart Attendance Tracking:** A modern interface for instructors to quickly and easily mark student attendance (e.g., present, absent, late).
* **Attendance Reporting:** Generate and view detailed attendance reports per student or per course, which can be filtered by date.
* **Secure Authentication:** A complete sign-up, login, and password management system for instructors.

This project was built using a modern technology stack:

* **Database:** Supabase (PostgreSQL)
* **Authentication:** Supabase
* **Email Service:** Resend
* **Deployment:** Vercel
